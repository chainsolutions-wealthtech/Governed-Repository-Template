This chronicle is a conversation-continuity memory. It does not replace repository business/governance authorities such as `CURRENT_STATE`, `PROGRAM`, `TASKS`, `NEXT_ACTION`, `DECISIONS_LOG`, checkpoints, handoffs, or live GitHub state.

## 1. Memory architecture

Rules active from activation forward:

- append-only chronology;
- stable monotonic IDs;
- corrections by new event + `supersedes/superseded_by`, never silent rewrite;
- no secret values, private keys, bearer tokens, cookies or credentials;
- no private chain-of-thought storage;
- external volatile states stored as `OBSERVED_AT` and revalidated before future mutation;
- no claim of background processing without an explicit automation;
- exact message text preserved when actually available;
- inaccessible historical raw turns are never reconstructed as a fake transcript;
- historical facts recovered later are appended as `HISTORICAL_RECOVERY`.
