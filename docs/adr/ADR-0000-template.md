# ADR-0000 — Initialize Governed Repository

- Status: `ACCEPTED`
- Date: `{{INITIALIZED_AT}}`
- Repository: `{{REPOSITORY}}`

## Context

The repository is initialized from the Chainsolutions Governed Repository Template.

## Decision

Adopt persistent project memory, Loop Engineering, explicit source-of-truth hierarchy, zero-regression discipline, verification before/after writes, and documented handoff.

## Consequences

- project-specific decisions remain to be added;
- template defaults do not imply product, legal, compliance, production or infrastructure approvals;
- future architectural decisions must be versioned.
